How to Use the Manager System

1. Login to the System

To access the manager dashboard:

  1. Open the manager login page.
  2. Enter your username and password.
  3. Enter the manager security code.
  4. Click Login.

2. Add New Reservation

The manager can also create reservations just like the receptionist.

  1. Open the Add New Reservation page.
  2. Enter guest details such as name, address, phone number, and email.
  3. Select a room type.
  4. Select check-in and check-out dates.
  5. Choose an available room number.
  6. Enter the number of adults and children.
  7. Click Save Reservation.

The system automatically checks room availability and prevents double booking.

3. View Booking Details

This section allows the manager to check all room statuses.

  1. Open the View Booking Details page.
  2. Use filters to search by room type, room status, or room number.
  3. Booked rooms display guest details.
  4. Available rooms are marked clearly.

4. Calculate and Print Bill

  1. Open the Calculate & Print Bill page.
  2. Enter the reservation number.
  3. Click Get Details.
  4. The system calculates total nights, room charges, tax, and total amount.
  5. Click Print Bill to print the invoice.

5. Checkout Guest

  1. After generating the bill, click Checkout.
  2. The reservation will be removed from the database.
  3. The room will become available again for new bookings.

6. Manage Rooms

The manager can manage room types and room numbers.

  1. Open the Manage Rooms page.
  2. View all room types and their details.
  3. Edit room type information such as price, max adults, max children, and features.
  4. Add new room numbers to a room type.
  5. Remove room numbers from a room type if needed.

7. Modify Reservations

  1. Open the Modify Reservations page.
  2. Search reservations using reservation number, guest name, phone, or room number.
  3. View reservation details in the table.
  4. If needed, delete a reservation from the system.

8. View Reports

  1. Open the View Reports page.
  2. Select a start date and end date.
  3. Apply the date filter to view report data.
  4. Use reports to monitor reservation activity and hotel performance.

9. Logout

  1. Click the Logout button from the dashboard.
  2. The system will end the session and redirect to the login page.
